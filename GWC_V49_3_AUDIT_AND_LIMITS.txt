IMPORTANT REQUESTS NOT IMPLEMENTED / DEPLOYMENT LIMITS
1. Website/domain block security:
   This archive does NOT yet enforce an Admin-maintained website block list at the
   Google Apps Script endpoint. Apps Script web-app events do not expose a trustworthy
   browser Origin header for this purpose. A UI-only block list or a check based only
   on Referer/Origin at a public proxy is not strong security (headers can be omitted
   or forged, and the public /exec URL can be called directly). To meet the requested
   security property, the deployment needs a server-verifiable signed request/token
   between a trusted proxy and Apps Script, plus a blocklist enforced by that trusted
   proxy, and the direct Apps Script endpoint must reject unsigned calls. This requires
   coordinated Apps Script + Cloudflare Worker/Render environment configuration and
   testing before it can be called secure. No claim is made that growthworldclasses.com
   is blocked by this candidate ZIP.
2. Render bandwidth:
   Bandwidth is metered network traffic, not a pile of files that can be deleted.
   Deleting old files/data does not erase already-consumed monthly bandwidth or reset
   the meter. The archive already includes worker.js + wrangler.toml + public assets,
   so the static site can be served by the Cloudflare Worker when deployed with its
   assets binding and GWC_API_URL. Merely adding those files to a ZIP does not move
   the live site off Render; DNS/deployment must be changed and verified.
3. Unused data cleanup:
   The app has Drive archive/deleted-folder tools, but it cannot reliably infer which
   Drive files are unused without a verified reference scan. Permanent deletion is
   destructive and Drive trash/retention behavior is controlled by Google. No
   automatic "unused" purge has been added.
4. Existing cloud records:
   This ZIP does not contain the live Google Sheet data. Keep the same Apps Script
   project, spreadsheet ID, Script Properties, and deployment when applying updates.
   Do not replace the live spreadsheet with an empty sheet.
