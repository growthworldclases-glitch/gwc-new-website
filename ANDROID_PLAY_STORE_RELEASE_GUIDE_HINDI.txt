GWC ANDROID APP — BUILD & GOOGLE PLAY RELEASE GUIDE
Project: android-app/
Package ID: in.growthworldclasses.app
Website: https://growth-world-classes-2-0.onrender.com

A. इस अपडेट में Android build configuration
- compileSdk = 36
- targetSdk = 36 (Google Play के 31 Aug 2026 से लागू नए ऐप नियम के अनुसार)
- minSdk = 23
- Android Gradle Plugin = 8.10.1
- Gradle distribution = 8.11.1
- JDK = 17
- Application ID = in.growthworldclasses.app (Play Store पर प्रकाशित होने के बाद इसे न बदलें)
- versionCode = 1 / versionName = 1.0.0 (पहली रिलीज़ के लिए)

B. Android Studio में तैयार करें
1. Android Studio Meerkat 2024.3.1 Patch 1 या उससे नया stable version install करें।
2. SDK Manager में Android 16 / API 36 Platform और Android SDK Build-Tools 36 install करें।
3. JDK 17 चुनें: File > Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK.
4. इस project का android-app folder खोलें।
5. इस source archive में Gradle wrapper properties मौजूद हैं; wrapper scripts/JAR नहीं हैं। यदि Android Studio wrapper generate नहीं करता, पहले Gradle 8.11.1 install करके android-app folder के Terminal में चलाएँ: gradle wrapper --gradle-version 8.11.1
6. Sync Project with Gradle Files करें और किसी भी dependency/SDK error को ठीक करें।

C. APK बनाना (पहले testing)
- Build > Build Bundle(s) / APK(s) > Build APK(s)
- Debug APK path: app/build/outputs/apk/debug/app-debug.apk
- यह केवल testing के लिए है। इसे Play Store production release के रूप में upload न करें।
- फोन पर install करके Login, logout, fee slip upload, salary proof upload, PDF download, links, back button, network loss और Android 16 पर व्यवहार जाँचें।

D. Signed Release APK और AAB
1. Build > Generate Signed Bundle / APK खोलें।
2. APK चुनकर signed release APK बनाएँ; यह direct installation/controlled distribution के लिए है।
3. फिर यही wizard खोलकर Android App Bundle (AAB) चुनें; Play Store के लिए AAB upload करें।
4. पहली बार नया upload keystore (.jks) बनाएँ। Strong password रखें। Keystore और passwords की कम-से-कम दो सुरक्षित offline backups रखें। इन्हें ZIP, GitHub या किसी व्यक्ति को न भेजें।
5. Play App Signing में enroll करें। आपका upload key आपके पास रहेगा; Google app signing key सुरक्षित रखेगा।
6. App ID वही रखें: in.growthworldclasses.app. Version code हर अगली release में बढ़ाएँ।

E. Play Store policy तैयारी
- Website owner/admin की अनुमति आपके पास होनी चाहिए; इस ऐप में अपना GWC website domain ही load करें।
- केवल website खोलने वाला thin WebView wrapper अस्वीकृत हो सकता है। Google WebView/limited-functionality policy लागू करता है। GWC app की वास्तविक उपयोगिता—student/teacher/admin login, classes, fee/salary workflows, uploads/downloads, helpdesk आदि—review में साफ़ दिखाई देनी चाहिए और बिना टूटे काम करनी चाहिए। Approval की गारंटी नहीं है।
- App listing में screenshots वास्तविक Android app से लें; गलत/भ्रामक screenshots न दें।
- Public Privacy Policy URL दें और उसमें login data, student/teacher records, uploaded fee/salary documents, storage, sharing, retention और contact details सही-सही बताएं। URL अभी project में तय नहीं है।
- Play Console Data safety form, App access (reviewer login/demo instructions), Content rating, Target audience, Ads declaration (यदि लागू हो), permissions declaration और store listing पूरी करें।
- Reviewer के लिए valid demo Admin/Teacher/Student accounts दें यदि app login के बिना review नहीं हो सकता। असली user passwords कभी न दें।
- Google Play User Data policy के अनुसार sensitive personal/financial documents के लिए स्पष्ट disclosure, secure transmission और limited access रखें।

F. Personal developer account testing
- यदि आपका Personal developer account 13 Nov 2023 के बाद बना है, तो production access से पहले कम-से-कम 12 testers को Closed testing में लगातार 14 दिन opted-in रहना होगा। Play Console के वर्तमान dashboard में eligibility/requirements जाँचें।
- पहले Internal testing, फिर Closed testing, फिर production access application करें।

G. Launch से पहले अनिवार्य test checklist
[ ] Admin, Teacher और Student के अलग-अलग test accounts से login/logout
[ ] Existing website IDs/passwords और roles सही काम करते हैं
[ ] Fee receipt / salary slip / proof file upload और replace
[ ] PDF/image download और Android Downloads में file उपलब्ध
[ ] Google sign-in/Workspace flows (यदि website में प्रयुक्त हों) supported browser handoff के साथ test
[ ] Back button, external links, WhatsApp/tel/mail links
[ ] slow network, offline, server unavailable, session timeout
[ ] Android 13, 14, 15, 16 devices/emulators पर परीक्षण
[ ] privacy policy, data safety और Play listing वास्तविक app behavior से मेल खाते हों
[ ] Play Console Pre-launch report और policy status clear

महत्वपूर्ण सीमाएँ
- यह source configuration update है, compiled APK/AAB नहीं। इस environment में Android SDK/Gradle उपलब्ध नहीं थे; इसलिए build, signing और device tests नहीं किए गए।
- ZIP में कोई keystore/password शामिल नहीं है। अपना keystore स्वयं बनाएँ।
- Website के Admin Branding controls से website का logo/poster बदलने पर website content app के WebView में load होने के बाद दिखाई देता है। Android launcher icon APK में bundled है; इसे बदलने के लिए नई APK/AAB release चाहिए।
- Native app splash पर Admin द्वारा live poster बदलने की सुविधा अलग native/website integration मांग सकती है; इस source update से launcher splash dynamically editable नहीं बनता।
- Live website, Render, Apps Script, Google Drive/Sheets, वास्तविक login और salary/fee uploads का कोई live test नहीं किया गया।
