GWC V32.3 — Unified Assigned Students + Monthly Fee Register

मुख्य बदलाव:
1. V30 के Login ID, Password, authentication, teacher/student portals और backend files को यथावत रखा गया है।
2. V32.2 के additive features और parent fee-slip upload/re-upload approval नियम बरकरार रखे गए हैं।
3. Admin का अलग Fee Management menu हटाकर month-wise fee register Assigned Students में जोड़ा गया है।
4. Month selector से महीने के अनुसार student fee receipt, payment last date और slip देखी जा सकती है।
5. Admin receipt attach/replace कर सकता है; parent द्वारा upload की गई slip भी उसी monthly record में दिखाई देती है।
6. Admin द्वारा चुनी गई payment last date के अगले दिन course access बंद हो जाता है।
7. Free Slots में वे active courses दिखते हैं जिनमें कोई active assigned student नहीं है; Assign Student से दोबारा allot किया जा सकता है।
8. Legacy fee data को delete नहीं किया गया है। पुराने stored records compatibility के लिए बने रहते हैं, पर duplicate fee menus नहीं दिखते।

महत्वपूर्ण: ZIP deploy करने से पहले अपने Google Apps Script / hosting project का backup रखें। पहली बार deployment के बाद Admin account से हर महीने की payment last date सेट करें।
