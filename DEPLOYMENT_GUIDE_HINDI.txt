C. Apps Script अपडेट
1. मौजूदा Apps Script Project खोलें (उसी Project का उपयोग करें जिसका Web App URL वर्तमान HTML में है)।
2. Code.gs को ZIP के Code.gs से बदलें।
3. Apps Script में Add file > HTML चुनें और नाम index रखें।
4. index.html की पूरी सामग्री उसमें Paste करें।
5. Script Properties में GWC_SPREADSHEET_ID और GWC_DRIVE_FOLDER_ID को न बदलें। Spreadsheet ID वही होनी चाहिए जिसमें सही 17:56 डेटा है।
6. Project Settings में Time Zone = Asia/Kolkata रखें।
7. Save करें।
8. Deploy > Manage deployments > Edit > New version करें। Existing Web App URL और सही access setting सुरक्षित रखें।
9. Web App URL को बिना action parameter के खोलें। अब वेबसाइट Apps Script से serve होनी चाहिए।
10. Apps Script Editor में installGwcV17Triggers() एक बार Run करें और permissions दें।

D. Hosting
- Apps Script-hosted mode में अलग Render/Node Hosting की जरूरत नहीं है।
- server.js और package.json ZIP में backward compatibility के लिए रखे गए हैं। यदि पुरानी static website Render पर चलती रहेगी, तो वही proxy mode भी उपलब्ध है।
- नए GAS-hosted mode में google.script.run से सीधे उसी Apps Script project के backend को कॉल किया जाता है।

F. अगर Sync Fail हो
- Retry पर stale revision error आए तो उसी tab से बार-बार Save न करें।
- Page reload करके नवीनतम Server State लोड करें।
- Apps Script Executions, GWC_Storage_Stage और GWC_Recovery_Backups जाँचें।
- Primary/Stage/Backup tabs को delete न करें।
- Error के समय Spreadsheet की copy और execution log सुरक्षित करें।

H. Login Safety
Cloud state verify hone se pehle login disabled rahega. Isse HTML ke fallback/default data ko real login database nahi maana jayega. Sync successful hone ke baad saved credentials hi use honge; unhe reset nahi kiya gaya hai.

I. दो Apps Script URLs का अंतर
पुराने index.html और server.js में दो अलग Deployment URL मिले हैं। पुराने Proxy mode में server.js वाला URL वास्तव में इस्तेमाल होता है। यह अनुमान न लगाएँ कि कौन सही है। V17 GAS-hosted mode में google.script.run उसी Apps Script Project को कॉल करता है जो वेबसाइट serve कर रहा है। यदि पुराने Proxy को चालू रखें तो GWC_API_URL को जाँचे गए अधिकृत Deployment URL पर सेट करें।
