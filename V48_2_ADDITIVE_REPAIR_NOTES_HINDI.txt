GWC V48.2 — DATA-PRESERVING ADDITIVE REPAIR

आधार: GWC_V48_1_FEE_REGISTER_DISPLAY_FIX.zip

इस अपडेट का उद्देश्य:
1. पुराने gwcMonthlyFees, feeRequests, student.slip तथा archived slip URL रिकॉर्ड को केवल पढ़कर Fee Register में दिखाना। कोई startup migration, reset या bulk overwrite नहीं किया जाता।
2. Fee Register में सभी महीनों की Slip History जोड़ना; active और archived URLs अलग दिखेंगे।
3. Admin के लिए Student Fee Update: अगली payment date, validity dates और fee slip photo एक ही action में दर्ज करना। पिछली slip URL history में बनी रहेगी।
4. Forced Start को fee cycle से स्वतंत्र करना: Admin द्वारा From और Last Date देने पर, बिना किसी fee slip के भी assigned/new student को उसी date window में Join My Class दिखेगा। Window खत्म होने पर access बंद होगा।
5. Admin-only Credentials & Batch Availability section: role filter, Teacher/Student list, batch assignment और occupancy status। Password values केवल authenticated Admin UI में दिखते हैं; इसे सार्वजनिक/शेयर न करें।
6. मौजूदा IDs, passwords, settings, sheet data, login records और पुराने modules को बदलने या हटाने का कोई migration नहीं।

महत्वपूर्ण सीमाएँ:
- ZIP में live Google Sheet/Drive का वास्तविक data नहीं होता। यदि live records/Drive files सचमुच delete हो चुके हैं, तो उन्हें ZIP से पुनः प्राप्त नहीं किया जा सकता। यह patch केवल मौजूद state में पुराने URL/history fields को फिर से दिखाता है। वास्तविक restore के लिए Google Sheet/Drive backup आवश्यक होगा।
- Google Meet account persistence Google/Android account session पर निर्भर है; GWC इसे force नहीं कर सकता।
- वास्तविक Render + Apps Script + Android end-to-end परीक्षण deploy के बाद करना होगा।
