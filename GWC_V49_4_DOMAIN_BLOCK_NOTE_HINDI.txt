GWC V49.4 — RAILWAY DOMAIN BLOCK NOTE
====================================

इस ZIP में केवल Railway server.js और documentation अपडेट किए गए हैं।
मौजूदा index.html, public/index.html, Code.gs, Apps Script logic, Google Sheet
schema, login/password flow, fees, courses, settings और Drive operations नहीं बदले।

DOMAIN BLOCK
------------
Default blocked hostnames:
- growthworldclasses.com
- www.growthworldclasses.com

जब इन hostnames का DNS इस Railway service पर point करेगा, server इन hostnames
पर आने वाली website और /api/gwc requests को HTTP 403 से रोक देगा।
बाकी hostname (जैसे Railway का generated *.up.railway.app domain या कोई दूसरा
custom domain) इस block से प्रभावित नहीं होगा।

Optional Railway Variable:
GWC_BLOCKED_DOMAINS=growthworldclasses.com,www.growthworldclasses.com

महत्वपूर्ण सीमा:
यह Railway server पर host-based block है। यह तभी लागू होगा जब blocked domain
का traffic इसी Railway service तक पहुँचे। यदि domain किसी दूसरे hosting पर
point करता है, तो यह ZIP उस दूसरे hosting को नियंत्रित नहीं कर सकती।

यह बदलाव Google Apps Script के public /exec URL को स्वयं बंद नहीं करता।
कोई व्यक्ति यदि Apps Script /exec URL सीधे जानता है और Apps Script deployment
अभी Anyone access पर है, तो वह URL अलग से खुल सकता है। केवल website domain
को deny करना और Apps Script endpoint को globally secure करना अलग-अलग बातें हैं।
Apps Script endpoint को वास्तव में केवल trusted proxy से चलाने के लिए coordinated
shared-secret authentication Code.gs और server.js दोनों में लगानी होगी; ऐसा
करने से सभी authorized proxy deployments पर authentication लागू होगी, न कि
केवल एक domain पर। इस ZIP में ऐसा global behavior नहीं जोड़ा गया है ताकि
मौजूदा दूसरे domains के integration अनजाने में बंद न हों।

DEPLOY
------
1. ZIP extract करें; ZIP file को GitHub में अकेले upload न करें।
2. Extracted contents को existing GWC GitHub repository के root में रखें।
3. Railway existing service में redeploy करें; नया service/database/volume न बनाएँ।
4. GWC_API_URL को existing Apps Script /exec URL पर ही रखें।
5. Railway generated domain पर /healthz और GWC login/notes/Drive workflows test करें।
6. growthworldclasses.com को इस Railway service पर point करने के बाद यह host 403 देगा.
   यदि आपका उद्देश्य इस domain को block करना है, तो इसे public DNS पर point न करें।
7. पुराने hosting को test पूरा होने तक बंद न करें।

TEST LIMITS
-----------
Offline ZIP integrity और JavaScript syntax validate किए गए हैं। Live Railway,
Google Apps Script, Google Sheet, Drive, login और production DNS tests नहीं किए गए।
