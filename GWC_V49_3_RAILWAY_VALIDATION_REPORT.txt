GWC V49.3 RAILWAY SIGNED-PROXY + DOMAIN SECURITY — OFFLINE VALIDATION
=======================================================================
Base: user-uploaded GWC_V49_3_RAILWAY_DRIVE_OPTIMIZED.zip

Preservation:
- Existing application HTML, Code.gs helper functions, data schema, assets,
  reports, login/account structures, courses, fees, settings and Drive operations
  retained, except coordinated doGet/doPost request authentication changes.
- Existing Google Sheet remains the structured-state database.
- Google Drive remains the file/attachment storage.
- No live data migration, spreadsheet replacement or credential reset.
- No Railway database or Persistent Volume added.

New changes:
- Express serves ONLY the public/ folder.
- Apps Script deployment URL removed from browser HTML and kept in Railway env.
- Railway signs Apps Script GET/POST envelopes with HMAC-SHA256.
- Apps Script rejects unsigned requests, stale timestamps and replayed nonces.
- Admin > Website Domain Security page added.
- Domain changes require re-entering the current Admin password and are saved
  server-side in the existing Google Sheet state.
- Railway checks request Host, Origin and Referer against the Admin blocklist.
  Exact domains and their subdomains are blocked; cache refresh is up to 15 sec.
- Railway /healthz reports whether HMAC proxy configuration is present.

Offline tests:
- ZIP integrity checked.
- package.json, appsscript.json and railway.json JSON parsing checked.
- server.js, worker.js and Code.gs JavaScript syntax checked with Node.
- All inline JavaScript blocks in index.html syntax checked with Node.
- index.html and public/index.html byte equality checked.
- HMAC algorithm format and configuration flow reviewed.

Not tested:

- Live Google Sheet writes, Drive upload/download, Admin/Student login.
